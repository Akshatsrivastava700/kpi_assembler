KPIAssembler runs as a sidecar service. Your product can consume its versioned REST API or embed the complete workflow with one web component.

01 · WEB COMPONENT

Embed the complete UI

Works in Rails, React, Angular, Vue, plain HTML, or any application that renders a webpage.

<script src="http://localhost:9292/kpi-assembler.js"></script>
<kpi-assembler
  service-url="http://localhost:9292"
  height="820px">
</kpi-assembler>
02 · REST API

Build your own experience

Use the certification engine from a mobile app, backend, BI surface, or existing admin panel.

    "paid_mrr"

Application setup

  1. 1
    Run the servicebundle exec ruby bin/kpi_assembler_web
  2. 2
    Connect an application databaseKPI_DATABASE_URL=postgres://user:pass@host:5432/application
  3. 3
    Limit tables / tenantKPI_INCLUDE_TABLES=orders,customers,accounts KPI_TENANT_ID=123
  4. 4
    Restrict browser access in productionKPI_ALLOWED_ORIGIN=https://your-app.example
Important

Use a read-only database user or replica in production. KPIAssembler executes candidate queries during certification.
